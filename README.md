# Kirill Petrov

**Senior Software Engineer · .NET · Architecture, performance and distributed systems**

I design and build software for scientific and industrial applications, from computational pipelines and backend services to interactive browser visualization. My experience includes industrial measurement software at Emerson and scientific data processing at the Institute for Analytical Instrumentation (IAP). I work across architecture and implementation, with a focus on making complex engineering tools usable and maintainable.

My current work includes **[SequenceHub](https://github.com/pkvspb/sequencehub-public)**, a platform for Sanger DNA sequencing analysis. It brings together an ASP.NET Core backend, plugin-based processing, Canvas visualization and deployment options spanning desktop applications and distributed workers.

- [SequenceHub documentation](https://github.com/pkvspb/sequencehub-public#documentation) — architecture, processing and deployment design.
- [SeqTrace](https://github.com/pkvspb/seqtrace-public) — linked trace visualization with shared and independent zoom and scrolling; vanilla JavaScript and React examples.
- [SeqNucs](https://github.com/pkvspb/seqnucs-public) — nucleotide visualization with quality coloring and selection.
- [RawGraph](https://github.com/pkvspb/rawgraph-public) — interactive visualization of multichannel fluorescence data.

The repositories above share documentation and integration examples from this work. See each repository for component licensing and usage terms.
